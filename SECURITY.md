# Security policy / Sicherheitshinweise

MXRouty runs locally and uses no network or online services. If you find a security issue
(e.g. a crash that can be triggered by MIDI data or a preset file), please report it via
GitHub's **private vulnerability reporting** on this repository ("Security" → "Report a
vulnerability") instead of a public issue.

MXRouty läuft lokal und nutzt kein Netz und keine Online-Dienste. Sicherheitsprobleme (z. B. ein
Absturz, der sich über MIDI-Daten oder eine Preset-Datei auslösen lässt) bitte über die
**private Schwachstellenmeldung** von GitHub in diesem Repository melden („Security" → „Report a
vulnerability"), nicht als öffentliches Issue.
