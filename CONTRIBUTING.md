# Contributing / Mitmachen

- Bug reports and feature requests: please use the issue forms (device, OS, MXRouty version,
  steps, log excerpt if available).
- Pull requests: small, focused changes; describe what and why; Windows and Linux must both keep
  working (the Linux side uses ALSA — see the notes in `core/ports.py`).
- Code style: Python 3.10+, no new dependencies without discussion, UI texts in English,
  comments may be German or English.
- Run `python tests_core.py` before submitting; it needs no MIDI hardware.
- By contributing you agree that your contribution is licensed under GPL-3.0-or-later.

Fehlerberichte und Wünsche bitte über die Issue-Formulare; Pull Requests klein und begründet,
Windows und Linux müssen weiter funktionieren; `python tests_core.py` vor dem Einreichen laufen
lassen. Beiträge stehen unter GPL-3.0-or-later.
